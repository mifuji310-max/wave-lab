# Contributing

The repository is currently owner-led and may remain private during early development.

## Workflow

1. Create or select an issue.
2. Confirm acceptance criteria.
3. Create a short-lived branch.
4. Implement the smallest complete change.
5. Run tests and validation.
6. Update documentation.
7. Open a pull request.
8. Merge only after review.

## Branch names

- `feature/<topic>`
- `fix/<topic>`
- `docs/<topic>`
- `spike/<topic>`

## Definition of done

- Acceptance criteria met
- Tests added or updated
- Documentation updated
- No unexplained dependency
- Mobile impact considered
- Physics impact validated when applicable
- Known limitations recorded
