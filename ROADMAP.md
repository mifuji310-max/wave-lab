# Roadmap

## Phase 0 — Repository foundation

- Approve charter and requirements
- Approve initial technical hypotheses
- Establish issues and decision records
- Select license before public release

## Phase 1 — Performance and physics spike

Deliver a minimal prototype:

- Worker-based scalar wave solver
- One pulse source
- 2D color rendering
- Pause and reset
- Observation sample
- Android performance report

Exit criteria:

- Stable solver
- Measured performance
- Confirmed grid targets
- Decision on Three.js and frame-transfer strategy

## Phase 2 — Core experiment editor

- Sources
- Walls
- Slit
- Observer
- Responsive portrait/landscape UI
- Save and restore locally

## Phase 3 — Learning content

- Four guided lessons
- Prediction prompts
- “Learn more” explanations
- Experiment notes

## Phase 4 — v0.1 release candidate

- 2.5D view
- Accessibility pass
- Physics validation report
- Device test matrix
- PWA packaging
- Documentation

## Later candidates

- Doppler effect
- Moving source and observer
- Audio representation
- Huygens visualization
- Multiple observers
- Experiment sharing
- Teacher-authored lessons
- Light and sound conceptual views

These candidates are not commitments.
