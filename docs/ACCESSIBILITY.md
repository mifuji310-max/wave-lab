# Accessibility

## Requirements

- Core controls operable by keyboard on desktop
- Clear focus indicators
- Touch targets sized for mobile use
- No essential meaning conveyed by color alone
- Text labels for icon-only controls
- Screen-reader names for controls and values
- Reduced-motion behavior where feasible
- Plain-language explanations
- Layout usable at increased text size

## Simulation alternatives

A visual field alone is insufficient for some learners. Provide:

- Numeric observer values
- Time waveform graph
- Descriptive lesson text
- Pause and step controls
- Future consideration: sonification, only after accessibility review

## Testing

Accessibility checks are part of each release, not a final-stage addition.
